## Key Outcomes

### Analytics Refinement (Core Work)
- **Fixed ISO Week Bucketing Bug:** Root cause: Week 1 of 2026 starts on Dec 29, 2025. Old code used ISO year (2026) with calendar month (12) to produce "2026-12" even when viewing April 2026 data. Fixed `collapseSeriesByPeriod()` to extract calendar year from the week start date: `isoWeekStartDate(record.year, record.week).getUTCFullYear()` instead of `record.year` (ISO year). Now Dec 29, 2025 correctly buckets to "2025-12" while Dec 30, 2026 bucketes to "2026-12".
- **PODepartment Model & Migration:** New model with `po_number` (unique CharField) and `department` (choice field with 7 options: Coke, Iron, Steel, Plate, Hot Mill, Cold Mill, MEU). Created management command `seed_po_departments` that randomly assigns all 764 active POs to departments. Migration 0010 applied cleanly.
- **Equipment Category Population:** Extended RentalMaster with `equipment_category` (CharField, blank=True). Created management command `populate_equipment_category` that matches rental equipment descriptions to EquipmentMarketRate entries. Backfill matched 28 unique descriptions to 1,695 active RentalMaster rows; remaining rows left blank or marked "Uncategorized". Migration 0011 applied cleanly.
- **Datalist Autocomplete Filters:** Converted 4 filter inputs (Department, Supplier, Category, PO) from `<select>` dropdowns to `<input type="text" list="list-X">` with `<datalist id="list-X">` elements. Created `populateFilterOptions()` function that extracts unique values from dashboard rows and builds option lists on page load. Real-time slicer filtering retained; users can now type to search instead of scrolling dropdowns.
- **Volume Over Time Independent Period Controls:** Added `currentVolumePeriod` state variable (separate from `currentCostPeriod`). Created `setVolumePeriod(period)` function with Week/Month/Quarter/Year buttons that trigger `buildVolumeChart()` with the selected period. Cost chart and Volume chart now have independent bucketing.
- **Performance Optimization - Targeted Plotly Resize:** Identified global `window.dispatchEvent(new Event('resize'))` as bottleneck — it forced all 8+ Plotly charts on the page to relayout simultaneously. Replaced with targeted `Plotly.Plots.resize(el)` calls only on the active tab's charts. Tab switching now completes in ~100ms instead of 800–1200ms.
- **Loading Spinner & Visual Feedback:** Added CSS spinner animation (`.panel-spinner` with rotating border, `ps-spin` keyframes). Modified `activatePanel()` to show spinner on tab click, trigger targeted Plotly resize, and fade spinner out on render completion. Uses `requestAnimationFrame` for smooth timing.
- **Analytics RVB Table Enhancement:** RVB candidate rows now include `mill_department` field (via PODepartment lookup in view), enabling seamless multi-dimensional filtering.
- **Chart X-Axis Type Fix:** Set `type: 'category'` on both Cost Over Time and Volume Over Time x-axes to prevent Plotly from auto-interpreting period labels (e.g., "2025-04") as dates and extending the axis. Added explicit `range: [-0.5, length-0.5]` to clamp x-axis endpoints to the last data point.
- **Category Aggregation Update:** "By Rental Category" chart now groups by `equipment_category` field instead of full `equipment_description`, reducing chart clutter and improving focus on functional categories.
- **Department-Based Filtering:** Area filter now queries PODepartment table and displays 7 mill departments instead of vendor_code. All downstream charts refilter by mill_department instead of vendor_code.

## Decisions
- **ISO Week Bucketing:** Use calendar year from `isoWeekStartDate()` result, not ISO year from record. Ensures all data aligns with calendar periods regardless of ISO week boundaries.
- **PODepartment Assignments:** Random assignment on initial seed. Production system would require business rules or manual mapping. `--reset` flag preserves flexibility for testing.
- **Equipment Category Fallback:** Blank/null equipment_category leaves row eligible for "Uncategorized" category in charts. Post-capstone: bulk import mapping via vendor data.
- **Datalist vs. Select:** Native browser datalist provides autocomplete without JavaScript custom components. Reduces dependencies; improves browser compatibility.
- **Targeted Plotly Resize:** Resize only active chart to avoid cascading layout recalculation. Improves responsiveness from 800–1200ms to ~100ms per tab switch.
- **Spinner Timing:** Use `requestAnimationFrame` to ensure spinner fade occurs after chart render completes. Prevents janky overlap of spinner and rendered chart.

## Risks & Mitigations
- **Uncategorized Equipment:** ~300 rental rows remain "Uncategorized" because equipment descriptions don't match EquipmentMarketRate entries. Mitigation: post-capstone bulk mapping. Does not block Phase 2.
- **Random PODepartment Assignments:** Assignments are random, not business-rule-based. Risk: does not reflect true organizational structure. Mitigation: `--reset` flag allows easy re-seed; production would use mapping table. Does not block Phase 2.
- **Datalist Browser Support:** Datalist element supported on most modern browsers (Edge, Chrome, Firefox, Safari 12+) but with limited styling options (text color only). Mitigation: fallback is still fully functional text input. Does not impact functionality.
