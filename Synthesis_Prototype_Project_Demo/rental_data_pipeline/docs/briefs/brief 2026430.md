## Key Outcomes

### Submission Window Logic
- **Rule Defined:** The vendor submission window opens at Monday 00:00 of the current ISO week (when `advance_cycle` creates `VendorAudit` records). It closes the moment the Junior Super User publishes that week's data, which is detected by checking whether `RentalMaster` rows exist for `cycle_week=current_week, cycle_year=current_year`.
- **`vendor_dashboard` View Updated:** Computes `window_closed` from a `RentalMaster.objects.filter(cycle_week, cycle_year).exists()` check and passes it to the template alongside `current_cycle_date`.
- **Three Action Views Enforced:** `vendor_declare_no_change`, `vendor_no_change_ajax`, and `vendor_csv_upload` each independently compute the current ISO week at request time and return an error/redirect if the window is closed.
- **Template Updated:** The submit button section now has three branches — window closed (locked badge), can submit (button), already submitted (checkmark). The CSV upload panel also hides when the window is closed.

### Developer Testing Commands
- **`reset_week`:** Deletes all `RentalMaster` rows for the target week and resets all `VendorAudit` records for that week to unverified/pending (sets `verified=False`, clears timestamps and notes). Accepts `--week` and `--year` args; defaults to current ISO week. Reopens the submission window for re-testing the full flow.
- **`bulk_submit_vendors`:** Marks all vendor audit records for the target week as verified/submitted except one designated test vendor (`vendor_smith_llc` by default). Also stamps staging rows with `cycle_week/cycle_year`. Accepts `--week`, `--year`, and `--skip` args.
- **README Testing Section Added:** New section documents submission window rules, both commands with all argument variants, and a step-by-step Week 18 test scenario.

### Vendor Cadence Feature Restored
- **Root Cause:** `VendorCompany` model had no `cadence` field. `advance_cycle` hardcoded `"weekly"` for every vendor, making the `SubmissionCadence` enum on `VendorAudit` meaningless.
- **Fix:** Added `cadence` CharField to `VendorCompany` (choices: `weekly`/`monthly`, default: `weekly`). Migration `0016_vendorcompany_cadence` created and applied.
- **Monthly Vendors Set:** 6 vendors marked `monthly` per `Vendor_Cycles.md`: Christensen Nixon and Davis, Davidson PLC, Lee-Jordan, Morales Allen and Jones, Preston LLC, West Inc. 19 vendors remain weekly.
- **`advance_cycle` Fixed:** Now reads `cadence` from `VendorCompany` via a `values('name', 'cadence')` query and stamps each new `VendorAudit` with the correct cadence. Output now labels each created record with its cadence.
- **Historical Backfill:** 69 existing `VendorAudit` records across all prior weeks updated to reflect the correct cadence.
