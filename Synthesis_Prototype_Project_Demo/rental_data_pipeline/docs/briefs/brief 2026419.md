## Key Outcomes
- Built `/review/` Weekly Review page for junior super users: stat cards, vendor submission breakdown, consolidated equipment table.
- Junior super users now blocked from `/admin/` — middleware redirects to `/review/`; `is_staff` stripped from all junior super user accounts.
- "Admin Portal" button on Analytics page is now role-aware: junior super users see "Reviewer Portal" → `/review/`; admins see "Admin Portal" → `/admin/`.
- Vendor Responses table updated to list all active `VendorCompany` records regardless of whether `advance_cycle` has been run for the week.
- Consolidated equipment table reformatted to match the Excel report format (13 columns: YEAR, WEEK #, DATE, RENTAL COMPANY, TYPE OF EQUIPMENT, EQUIPMENT #, EQUIPMENT DESCRIPTION, DATE RENTAL STARTED, PROJECTED END DATE, PO NUMBER, SERVICE NOW REQUEST #, MONTHLY RATE $, COMMENTS).
- "Download CSV" button added to consolidated table; filename includes week and year.
- UX/Testing checklist (Section 6) added to Implementation Plan covering all user actions and site functionality.
- **Cost Over Time tab** added as the default first tab on the analytics dashboard. Plotly line+fill chart reads weekly totals from `rental_master`. Auto-generated summary paragraph compares the last two visible periods with % change and severity label.
- **Period toggle** (Day / Week / Month / Quarter / Year) and **Visible Periods slider** added to Cost Over Time chart. Both filter and rescale the chart and summary client-side with no page reload.
- **Week Comparison tab** added to analytics dashboard. Backend computes equipment added or removed between the two most recent published weeks. Template renders two side-by-side tables: Placed On-Rent (green) and Taken Off Rent (red), each with vendor, equipment ID, description, and monthly cost.
- **`seed_w16` management command** created. Derives Week 16 from the W15 `RentalMaster` pool: ~10% dropout (77 lines taken off-rent), 10 new equipment lines placed on-rent across 6 vendor companies. All injected company names are fictional placeholders from the `VendorCompany` table — no real company names in any committed file.
- **Next-phase scope (W17)** documented in Implementation Plan Section 5D: 8 vendor data integrity scenarios covering normal submission, new equipment, removals, rate changes, validation failures, late submissions, non-submissions, and duplicate equipment IDs.

## Decisions
- Junior super users remain blocked from practical admin navigation by middleware redirect, but internal-role staff flags are retained for authentication plumbing while vendors remain non-staff.
- Weekly Review vendor list is sourced from `VendorCompany` (all active companies), not from existing `VendorAudit` rows, so it is always complete.
- Consolidated table column set is locked to the 13-column Excel format used by the operations team.
- Power BI is eliminated from this build. Plotly embedded in Django is the final analytics layer.
- All seed data must use fictional company names from the `VendorCompany` table. Real vendor names are prohibited in any committed file.
