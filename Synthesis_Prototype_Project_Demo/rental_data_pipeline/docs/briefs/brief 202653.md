## Key Outcomes

### Cadence Data Integrity
- **Root Cause Resolved:** All 25 vendors were seeded as `"weekly"` because `_get_or_create_company` in `seed_user_schema` never passed cadence to `defaults`. Fixed: cadence now set in `defaults` and explicitly saved on pre-existing records.
- **`_fix_vendor_cadences` Extended:** `demo_setup`'s step 0a now issues two ORM bulk updates — `VendorAudit.cadence` corrected for all historical rows (monthly vendors → `"monthly"`, remainder → `"weekly"`) in addition to `VendorCompany`.
- **`reset_week` Corrects Cadence:** After bulk-resetting audit rows to pending, loops over each row and syncs `cadence` from the `VendorCompany` map before saving.
- **"NOT REQUIRED" KPI Fixed:** The monthly cadence audit rows now have the correct value, so the reviewer dashboard's "NOT REQUIRED" count reflects actual monthly vendors.

### `demo_setup` Post-Reset Completeness
- **Missing Vendor Problem:** Brown Group and Trevino Inc were absent from W19's audit rows because a prior partial `advance_cycle` run never created them. After `--reset`, the old condition (`existing_audits == 0`) skipped `advance_cycle`, leaving the gap.
- **Fix:** `advance_cycle` now always runs after `--reset` (`condition: existing_audits == 0 or do_reset`). `get_or_create` ensures no duplicates. W19 now has 25/25 vendors all Pending.
- **`--no-submit` Flag:** New flag skips `bulk_submit_vendors` entirely; all vendors start Pending. State snapshot and walkthrough still print.

### Reviewer Dashboard: Smart Week Default
- **Problem:** Logging in on a Sunday (ISO still W18) showed a published W18 rather than the actionable W19.
- **Fix:** When `/review/` loads without `?week=`, view checks current week; if published or no audits, looks ahead up to 4 weeks for the nearest open cycle. Explicit `?week=` navigation unchanged.

### Reviewer Dashboard: Monthly Vendor Obligation Banner
- **`monthly_required` Flag:** Derived from whether any current cycle audit rows have `cadence == "monthly"`. Appended to the yellow delinquent-vendor ribbon.
- **W19 (first week of May):** Banner reads "Monthly vendors are required this week (first full week of May)."
- **W20–W22:** Banner reads "Monthly vendors are not required this week — they already submitted earlier in May."

### Vendor Portal: "Done for Now" Banner
- **Trigger:** `done_for_now = (audit is None or (audit.verified and window_closed)) and next_audit is not None`.
- **Display:** Orange ribbon with exact next window open date and time — e.g., "Monday, May 4 at 12:00 AM CST (Week 19, 2026)".
- **Covers:** Sunday-before-week case (no current audit) and published-week case (verified + window closed).

### `welcomeModal` Dismiss
- **× Button:** Added to top-right of modal; calls `welcomeDismiss()`.
- **Backdrop Click:** `onclick` guard on overlay div.
- **Shared Helper:** `_closeWelcomeModal()` extracted; used by Yes, No-confirmed, and Dismiss paths.
- **Session Key:** Set on dismiss so modal does not reappear in the same browser session.

### README Updates
- Monthly vendor submission window documented: "first full ISO week whose Monday falls within that month."
- "Grading on a Sunday?" callout with generic `--week <WEEK> --year <YEAR>` placeholder command.
- All hardcoded `--week`/`--year` examples in command docs replaced with `<WEEK>`/`<YEAR>` placeholders.
- Reviewer Flow step 8 links to Vendor Flow section via explicit `<a id="vendor-flow">` anchor.
- Vendor Flow step 6 links back to Reviewer Flow step 9 via `<a id="reviewer-step-9">` anchor.
