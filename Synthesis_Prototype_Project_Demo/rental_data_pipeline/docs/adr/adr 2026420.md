## Problem Statement
Refine the embedded analytics dashboard by fixing ISO week bucketing anomalies, replacing vendor-code-based area filtering with domain-specific mill departments, and optimizing chart performance and usability through searchable filters and independent period controls.

## Business Goals
- Correct monthly/quarterly/yearly visualization bucketing so historical data reflects accurate calendar periods (root cause: ISO week year vs. calendar year misalignment).
- Introduce mill department as the primary "area" dimension, replacing the generic vendor_code proxy.
- Populate equipment category from reference data to enable category-based utilization analysis.
- Improve filter UX with autocomplete datalist inputs, replacing static dropdowns.
- Reduce tab-switching latency with targeted Plotly resize and visual feedback.

## Analytics Users
- Administrator (read-only access, blocked from `/analytics/`)
- Junior Super User (primary analytics consumer)
- Vendor (blocked from `/analytics/`)
- Leadership via embedded portal analytics

## Data Sources
- `rental_master` table with new `equipment_category` field
- `PODepartment` table (new) mapping all active POs to 7 mill departments
- `EquipmentMarketRate` table for equipment category reference
- Existing `rental_audit` for compliance metrics

## Current Build Status (2026-04-20)

### Completed This Session
- **ISO Week Year Fix:** Root-cause identified: Week 1 of 2026 starts Dec 29, 2025. Old code paired ISO year (2026) with calendar month (12) to produce "2026-12". Fixed by using calendar year from `isoWeekStartDate()` result instead of ISO year from source record.
- **PODepartment Model & Seeding:** New model linking 764 distinct POs to 7 mill departments (Coke, Iron, Steel, Plate, Hot Mill, Cold Mill, MEU). `seed_po_departments` management command assigns randomly; `--reset` flag allows re-randomization.
- **Equipment Category Population:** Extended RentalMaster with `equipment_category` field. Backfill matched 28 EquipmentMarketRate descriptions to 1,695 active rental rows. Remaining ~300 rows marked "Uncategorized".
- **Searchable Filters:** Converted 4 filter inputs (Department, Supplier, Category, PO) from `<select>` to `<input type="text">` paired with `<datalist>`. Native browser autocomplete; real-time slicer synchronization retained.
- **Volume Over Time Period Controls:** Added independent Week/Month/Quarter/Year buttons to Volume chart; decoupled from Cost chart period state.
- **Performance Optimization:** Replaced global `window.dispatchEvent('resize')` with targeted `Plotly.Plots.resize(el)` calls on visible charts. Added CSS spinner overlay on tab transitions.
- **RVB Table Enhancement:** RVB candidate rows now include `mill_department` field for consistent filtering.

## Core Metrics
- Total on-rent spend by **mill department** and period (updated from vendor).
- Equipment category utilization trend.
- Vendor submission compliance rate (weekly and monthly cycle).
- Late submission count per cycle.
- Rent-vs-buy candidate opportunities by equipment category.

## Data Model Requirements
- `RentalMaster` extended with `equipment_category` (CharField, can be null → "Uncategorized").
- `PODepartment` model: `po_number` (unique) → `department` (choice from 7 departments).
- All references to vendor_code for "area" filtering replaced with mill_department via PODepartment join.

## Data Quality Rules
- Hard validation for date and currency fields (existing).
- Reject malformed records with actionable error output (existing).
- "No Changes" flag must be a verified action, not a default/null state (existing).
- Deadline timestamps stored on audit records for cycle compliance reporting (existing).
- Equipment category must be sourced from reference data; fallback to "Uncategorized" (new).
- PO→department assignment must be complete for all active POs (new).

## Known Limits After This Session
- 28 of 376 unique equipment descriptions matched to EquipmentMarketRate. Remaining rows show "Uncategorized". Post-capstone task: bulk update via vendor data import mapping.
- PODepartment assignments are random. Production would require business rules or manual mapping.
- No audit trail on PODepartment changes (can be added post-capstone via audit log system).

## Reporting Requirements
- **Primary (this build):** Embedded Plotly analytics at `/analytics/` with 5 tabs:
  1. **Cost Over Time:** Line chart, period buckling (week/month/quarter/year), visible window slider. Auto-summary paragraph.
  2. **Volume Over Time:** Line chart with independent period controls. Reflects equipment count trends.
  3. **By Department:** Horizontal bar chart (top 10 departments by cost).
  4. **By Supplier:** Horizontal bar chart (top 20 suppliers by cost).
  5. **By Rental Category:** Horizontal bar chart (top 15 equipment categories by cost).
  6. **Week Comparison:** Two side-by-side tables (placed on-rent green / taken off-rent red).
  7. **Compliance:** Vendor submission heatmap.
  8. **Rent-vs-Buy:** Candidates table (top 25 by savings, with mill_department included).
  9. **Ledger:** Raw RentalMaster dump with slicer filtering.

- **Slicer Controls:** Real-time filters for Week, Department (via PODepartment), Supplier, Category, PO. Datalist autocomplete on all text inputs.
- **Role Scoping:** Vendors blocked (403); admins blocked; analytics restricted to junior super users.
- **Period Bucketing:** Weekly data aggregated to monthly/quarterly/yearly using calendar year (not ISO year) with proper month boundary handling.

## Non-Functional Requirements
- Secure authentication and least-privilege role access (existing).
- SMTP credential handling must not appear in committed code (existing).
- Data refresh aligns with weekly (Thursday 2:00 PM CST) and monthly cadences (existing).
