## The Synthesis Prototype: Rental Data Pipeline

The capstone project transforms the management of a $2M–$3M annual equipment rental portfolio from a "personality-dependent" manual chore into a robust, prescriptive analytics ecosystem. By automating the consolidation of data from over 25 third-party vendors, the system eliminates the administrative bottleneck of a single human filter, while simulatenoulsy eliminating the weekly headache of hounding vendors for acccurate, up-to-date data.

Architecturally, the project integrates all four MS-CISBA pillars into a single "living organism." Software (the muscle) drives the interaction and validation logic. Networking (the nervous system) moves data securely across the application layer. Data Management (the skeleton) provides the rigid Relational Model necessary to store asset history. Analytics (the brain) translates that data into role-scoped, prescriptive intelligence for leadership.
